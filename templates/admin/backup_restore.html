Create backup

Generates a secure .zip archive with db.sqlite3, optional media/ files, and a manifest.json. Store it offline in a safe location.

Keep backup files private — they contain personal beneficiary and citizen data.

Replaces the current database (and media when included in the archive). Accepts an e-BAHAGI .zip backup or a raw .sqlite3 file.

Destructive action. Current data will be overwritten. Download a fresh backup first. All users may need to sign in again after restore.
